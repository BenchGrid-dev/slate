# 0005: Rust for all first-party components

- Status: accepted
- Date: 2026-09-26

## Context

slash, slated and slate-desktop are long-running, privileged, user-facing processes that speak Wayland protocols, run as a login shell, and hold the audit log.

## Decision

All first-party components are written in Rust in a single Cargo workspace. Wayland integration via wayland-rs / smithay-client-toolkit; compositor patches in whatever the compositor is written in.

## Consequences

- Single static binaries, easy to ship in an image.
- One toolchain for contributors.
- Skills and policy files are data, not code, and are not affected.
